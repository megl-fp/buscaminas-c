Tecnologías: Lenguaje C (estándar C99) y compilador GCC
Para el correcto uso del programa, siga estas indicaciones:

Asegúrese de tener en la misma carpeta los siguientes archivos:

    1-Buscaminas.c
    2-BuscaminasFunc.c
    3-FuncionesJuego.c
    4-BuscaMinas.h
    5-Dentro de esta carpeta, creé otra carpeta llamada "output" en la cual se guardará el archivo de usuarios 
    
    Debe contar con el editor de código Visual Studio Code.

Usando Visual Studio Code:

Abra la carpeta que contiene los archivos mencionados.
Abra el archivo Buscaminas.c.
Ejecute el archivo Buscaminas.c.
